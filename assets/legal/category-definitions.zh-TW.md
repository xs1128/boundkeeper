# Demo 分類定義

category id 對應 `corpus.zh-TW.json`，不變更 `AnalyzeResult` contract。以下是風險篩檢界線，不是個案法律認定。22 組固定範例包含原始五組與擴充正反案例；固定範例不代表實際模型分類準確率。

- `workplace_bullying`／職場霸凌風險：職務或權勢、不合理言行、工作關聯、持續性及身心危害須整體考量；情節重大不以持續發生為必要。來源 `osha-22-1`、`osha-bullying-handbook`。不能僅以「笨」「滾」等單字判定成立。
- `illegal_overtime`／加班與工資風險：分別確認要求工作、實際工時、給付、合法補休及特殊工時制度。來源 `lsa-24`、`lsa-30`、`lsa-32`、`lsa-32-1`、`lsa-42`、`lsa-84-1`。晚間傳訊不等於已加班，公司聲稱責任制也不等於免付加班費。
- `improper_transfer`／調動風險：依契約及調動五原則確認必要性、待遇、勝任能力、距離協助與家庭利益。來源 `lsa-10-1`。不能把所有調職或跨區調動直接判為違法。
- `forced_resignation`／解僱／逼退壓力：區分自願辭職、合意終止、法定資遣與懲戒解僱。來源 `mol-forced-resignation`、`lsa-11`、`lsa-12`、`lsa-14`、`lsa-16`、`lsa-17`、`pension-12`。不能看到「離職」便推定遭逼退或必然享有資遣費。
- `legal_management`／一般管理回饋：針對具體工作、合理時程或品質提出要求，單憑語氣嚴厲不足以標為霸凌。來源 `mol-reasonable-management` 及 `osha-22-1`。A2 的合理回饋 fixture 應為 `none` 或 `low`；不代表其他情境只要包含績效字眼就可以排除侵害。
- `sexual_harassment`／職場性騷擾風險：性要求交換工作待遇、冒犯性工作環境、權勢性騷擾及雇主未處理。來源 `gewa-1`、`gewa-2`、`gewa-12`、`gewa-13`、`gewa-32-1`、`gewa-36`。不套用霸凌持續性門檻，不要求被害人曾明確拒絕；非工作時間及特殊身分須另核對適用範圍。防治訓練及禁止騷擾通知是負例。
- `gender_discrimination`／性別／婚孕歧視風險：性別、性傾向、婚孕育兒造成的機會、薪資、福利或契約終止差別待遇。來源 `gewa-7` 至 `gewa-11`、`gewa-14` 至 `gewa-19`、`gewa-21`、`gewa-36`。依實際工作、年資或績效等正當理由的差異不當然違法。
- `employment_discrimination`／就業歧視／招募隱私風險：年齡、身心障礙等法定特徵歧視，及扣留證件、保證金或非就業所需隱私要求。來源 `esa-5`。合理資格核對、驗明身分後立即返還證件，不能直接視為侵害；不是完整個資法分析。
- `leave_rights`／請假與休息權益風險：例休、法定假日、特休、病假、性平相關假別、哺集乳及育嬰復職。來源 `lsa-35` 至 `lsa-39`、`lsa-43`、`gewa-14` 至 `gewa-21`、`leave-4`、`leave-7`、`leave-9`、`leave-9-1`、`leave-10`。核對假別、資格、程序與例外；十日不是全年病假上限，普通病假半薪與按比例扣全勤不當然違法。
- `wage_violation`／薪資給付風險：未全額或定期給薪、未提供明細、預扣賠償、特休未休及假日工資、最低工資。來源 `lsa-22`、`lsa-23`、`lsa-26`、`lsa-38`、`lsa-39`、`gewa-10`、`leave-9`、`minimum-wage-5`。依法代扣及合法假別給薪不能一概判為欠薪；加班給付仍可用 `illegal_overtime`。
- `retaliation`／申訴報復風險：因勞動申訴、性平申訴或協助他人性平申訴而受不利待遇，以及依法危險退避後受不利處分。來源 `lsa-74`、`gewa-36`、`osha-18`。須確認因果關聯；不是所有檢舉均直接適用這些規定。
- `unsafe_work`／危險作業風險：立即危險下仍要求作業及阻擋依法停工退避。來源 `osha-18`。優先安全、立即報告，不鼓勵冒險蒐證；一般工作不滿不等於立即危險。

產品顯示名稱採「風險」而非「違法確定」。不應把沒有足夠線索解讀成全面合法，也不能從主管訊息自行補出持續時間、心理診斷、薪資或契約內容。

執行時另有 `other`（資訊不足／其他勞動風險）及 `crisis`（優先確認人身安全）。前者不是確定法律分類，後者只能由核心的安全分流產生，模型不能選用。這兩者不列入上述12類法規情境。
