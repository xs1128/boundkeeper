# Web 展示流程（3 分鐘）

本流程使用「範例情境」中的「評審展示」組，不需要模型金鑰。網站與 `/api/analyze` 仍須可連線；範例分析不會呼叫外部 AI。不要修改範例輸入，修改後會切換為一般分析。

公開網址：https://genai-hack-amber.vercel.app

## 展示前

- 開啟已部署版本或本機網站，確認分析頁可載入。
- 使用 390 CSS px 寬度確認主要按鈕可操作、頁面不會水平捲動。
- 確認瀏覽器允許本機儲存；案件紀錄只會在同一瀏覽器、同一網站來源中保留。
- 僅使用合成範例，不貼上真實主管或同事的私人訊息。

## 展示步驟

1. **0:00–0:20**：說明用途：理解訊息中的風險，準備回覆方向與諮詢資料；結果是一般資訊，不是法律判決。
2. **0:20–1:00**：在「評審展示」選「言語羞辱與排擠」，按「檢查這則訊息」。展示高風險、白話解釋、多要件提醒與可展開的官方法規來源。
3. **1:00–1:30**：選「要求無薪加班」，再次檢查。展示工時與工資給付風險，避免把風險訊號說成法律認定。
4. **1:30–2:00**：選「嚴格但合理的績效回饋」，再次檢查。展示「無明顯風險」與合理管理回饋的解釋。
5. **2:00–2:30**：展示「改進建議」（不是可直接貼上的回覆草稿）。按「複製諮詢摘要」；成功會出現提示。若瀏覽器不允許自動複製，使用已選取文字的手動複製。
6. **2:30–3:00**：按「儲存到案件紀錄」，點「查看案件紀錄」，再下載 JSON。指出摘要不含主管原始訊息，以及只有明確儲存才保留分析紀錄。時間夠再加 LINE：以 https://line.me/R/ti/p/%40031qhelh 加入「界線守門員」，把同一則「言語羞辱與排擠」原文貼到官方帳號，展示 bot 回同一套分析。步驟與罐頭訊息排除見 [LINE 整合](line-integration.md)。

## 現場備援

- 一般分析不可用時，重新選擇範例情境再送出，不要修改原文。
- 網站連線失敗或等待超過 30 秒時，輸入內容仍保留；確認連線後按「重試分析」。
- 本機儲存受限時，保留畫面上的分析與諮詢摘要，換用允許網站儲存的瀏覽器後再儲存。
- 鍵盤可用 Tab 依序操作導覽、情境選擇、背景欄位、輸入、檢查、法規展開、複製與儲存；Enter 可啟動按鈕與展開法規。
