# Web 展示流程（3 分鐘）

本流程使用「範例情境」，不需要 OpenAI API key。網站與 `/api/analyze` 仍須可連線；範例分析不會呼叫外部 AI。不要修改範例輸入，修改後會切換為一般分析。

## 展示前

- 啟動本機網站或開啟已部署版本，確認分析頁可載入。
- 使用 390 CSS px 寬度確認主要按鈕可操作、頁面不會水平捲動。
- 確認瀏覽器允許本機儲存；案件紀錄只會在同一瀏覽器、同一網站來源中保留。
- 僅使用合成範例，不貼上真實主管或同事的私人訊息。

## 展示步驟

1. **0:00–0:20**：說明用途：理解訊息中的風險，準備回覆與諮詢資料；結果是一般資訊。
2. **0:20–1:00**：選「言語羞辱與排擠」，按「檢查這則訊息」。展示風險、白話解釋、多要件提醒與可展開的官方法規來源。
3. **1:00–1:30**：選「要求無薪加班」，再次檢查。展示工時與工資給付風險，避免把風險訊號說成法律認定。
4. **1:30–2:00**：選「嚴格但合理的績效回饋」，再次檢查。展示「無明顯風險」與合理管理回饋的解釋。
5. **2:00–2:30**：修改建議回覆，按「複製回覆」。成功會出現提示；若瀏覽器不允許自動複製，使用已選取文字的手動複製功能。
6. **2:30–3:00**：按「儲存到案件紀錄」，等待成功提示，再開啟「案件紀錄」並下載 JSON。指出結果內的法律資訊聲明，以及只有明確儲存才保留分析摘要的設計。

## 現場備援

- 一般分析不可用時，重新選擇範例情境再送出。
- 網站連線失敗或等待超過 30 秒時，輸入內容仍保留；確認連線後按「重試分析」。
- 本機儲存受限時，保留畫面上的分析與回覆，換用允許網站儲存的瀏覽器後重新執行範例。
- 鍵盤可用 Tab 依序操作導覽、情境選擇、輸入、檢查、法規展開、回覆、複製與儲存；Enter 可啟動按鈕與展開法規。
