# 台灣職場訊息風險擴充

核對日期：2026-09-04。用途是協助一般受僱者理解收到的工作訊息，不是完整企業法遵稽核或個案法律意見。

## 選用依據

勞動部2026-07-31公布的114年度工讀生與部分工時專案檢查中，前三大違規樣態是未加倍給付假日出勤工資、未依法安排例假及休息日、未給付休息日出勤工資，另有工資未全額給付及出勤紀錄問題。這是特定勞檢專案，不能推論為全台所有職場的違法率或通用排名。[官方檢查結果](https://www.mol.gov.tw/1607/1632/1633/96453/)

性平與性騷擾則依使用者提出的需求，以及工作訊息可直接呈現的風險選入，例如性要求交換升遷、懷孕即被要求離職、性別薪資差異及雇主拒絕處理性騷擾。[性別平等工作法](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0030014)

以下是需要核對的「風險因素」，不是看見關鍵字就能認定違法：

| 訊息中的因素 | 應核對的法規 | 本次接入 |
| --- | --- | --- |

| 年齡、身心障礙等就業歧視；扣留證件、保證金、非必要隱私 | 就服法第5條 | 就業歧視／招募隱私分類 |
| 不准特休、未休歸零、連續工作不給休息、拒絕法定假別 | 勞基法第35至39、43條；性平法第14至21條 | 請假與休息分類 |
| 普通病假一天就扣整月全勤，或只因病假降低考績 | 請假規則第4、9、9-1條 | 保留2026新制及依法半薪／比例扣全勤例外 |

| 已有立即危險仍被命令作業，或禁止停工退避 | 職安法第18條 | 危險作業分類，先安全退避與報告 |

## 已接入的範圍

執行時資料共56筆：六部法律48條、勞工請假規則5條、官方指引／問答3筆。原有五類情境保留，新增七類；另有資訊不足及危機分流。模型只能選資料集中的來源id，程式填回法規名稱、摘要、官方網址、限制與來源顯名。

22組固定範例包含17組新增案例，網頁範例選單自動顯示。負例涵蓋合理請假補件、依實際績效給薪、防治訓練通知及普通病假合法比例給付。規則只提供線索；實際訊息的語意判斷仍由模型處理，不能用固定範例或模擬模型回覆的測試通過率宣稱實際分類準確率。

## 仍需另行核對

- 性騷擾不以重複發生為一般必要條件，但非工作時間有特定關係與持續性條件；校園、公務、教育、軍職及公共場所不特定人事件另有程序分流。
- 本次未完整納入性騷擾防治法、性別平等教育法、個人資料保護法、勞健保投保、工會不當勞動行為、職災補償及所有安全衛生標準。不得擴張宣稱已支援。
- 法規命令僅收錄選定請假規則；育嬰留停申請程序、津貼、申訴期限及年度假日／最低工資金額不提供自動計算。
- 原文ZIP資料截止2026-08-21，官方頁核對日為2026-09-04；需定期人工核對後續修法，沒有自動更新保證。
- 自傷或傷人訊息仍先走既有安全分流。輸入訊息不新增伺服器保存，也不代為送出申訴。
